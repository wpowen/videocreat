# Codex Video Workflow 宣传口播系列

## 定位

- 视频类型：口播式能力宣传 / 产品解释
- 目标观众：想让 Codex 直接产出可复核本地视频包的创作者、开发者、运营人员
- 核心承诺：这个 skill 不是只渲染 MP4，而是把 brief、口播、分镜、动效、封面、QC 和交付证据串成一条可复现生产线。
- 权利边界：原创中文口播；本地生成视觉；本地 CosyVoice 或 MeloTTS；无真人声音克隆；无商业 stock；无外部平台素材。

## 口播稿

如果你让 Codex 做视频，最容易翻车的不是不会渲染，而是跳过了前面的判断。这个技能的价值，就是把视频当成一条完整生产线来管。它会先把需求变成生产合同：平台、时长、版权边界、口播风格、字幕策略、封面目标和质检标准，先写清楚，再开始动手。接着它会先生成口播材料。原始稿、口播稿、逐帧口播分段、语音方向都会落盘，停顿只放在完整句子或完整语义后面。画面也不是临时做几张卡片。它会选择内容展示系统、审美规则、动效模板和每一幕的视觉隐喻，再用本地可复现资产或 image2 提示接上画面。语音默认走本地 CosyVoice 或 MeloTTS，不走未授权真人声音，也不依赖付费云视频接口。音量、动态、长静音和字幕同步都会进入检查。最终交付的不只是一个 MP4。它还会给封面、多分辨率封面导出、截图、ffprobe、blackdetect、volumedetect、质量分数卡和本地 delivery 页面。所以这个技能适合做严肃的视频生产：先有内容逻辑，再有口播和动效，最后用证据证明它真的能看、能听、能复核。

## 口播节奏

- 风格：conversational，偏清晰的创作者口播。
- 停顿：只在完整句子或完整语义后换气；逗号不换行，不制造长停顿。
- 语气：先指出常见翻车点，再逐层展示生产线能力，最后收束为可复核价值。

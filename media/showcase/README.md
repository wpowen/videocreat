## 2026 core-demo evidence

`core-demo/` is a stable subset copied from the current semi-auto run generated from `media/oral-materials/core-capability-demo-2026-brief-zh.json`.

- `semi-auto-config.html` is the actual generated configuration console, not a hand-authored README mockup.
- `config-*.png` files are Chromium captures of that console. The locale captures exercise the runtime Chinese/English switch; the catalog captures show the rendered motion, caption, color, voice, cover-logic, and platform-size interfaces.
- `motion-style-template-review.html` and `vertical-motion-style-template-review.html` contain the 32-family × 5-variant review catalog.
- `generation-mode-contract.json`, `caption-style-plan.json`, and `cover-size-selection.json` preserve the structured decisions behind the visible UI.
- `cover/*.svg` files are **review previews**, not upload-ready cover bitmaps. Their incomplete status is kept visible in the main README.

The current full-auto demo MP4 and poster live directly under `media/`; `core-demo/full-auto-contact-sheet.jpg` shows all eight scenes. The 122.1-second video lane passed the current render, stream, timing, black-frame, silence, and visible-text checks after framework-level route and overflow fixes. The run remains non-publishing-ready until every requested platform cover is generated, inspected, ingested, and revalidated.

The expanded `config-*.png` gallery is generated by `scripts/capture-readme-showcase.mjs` from the actual console. It covers Chinese and English base settings, motion, captions, colors, material routing, covers, voice/localization, per-page editing, and both horizontal and vertical motion-browser pages.

## Previous catalog capability reel

`capability-reel/capability-showcase.mp4` is a deterministic 38.4-second, 1920×1080 catalog reel generated by `scripts/render-capability-showcase-demos.mjs` from the committed motion and caption manifests plus the generated configuration console.

- It walks all 32 motion families and displays all five variants for each family.
- It proves union coverage for all 160 motion-style contracts, 44 configuration color systems, and 68 routable caption styles across eight groups.
- It records that the catalog is backed by six executable HTML cores but does **not** misrepresent 160 contracts as 160 independent renderers.
- It contains local MeloTTS narration and committed probe, black-frame, volume, silence, coverage, and QC logs.

This older reel is retained as catalog-union regression evidence. It is not the primary promotional demo because its generic geometry does not explain each motion's semantic job.

## 它解决什么问题

很多视频工具只负责“生成一段画面”。Codex Video Workflow 负责的是一条完整生产链：理解内容、组织叙事、选择视觉表达、生成口播与字幕、制作平台封面，并把结果整理成方便审阅和继续修改的交付包。

它适合：

- **内容创作者**：把文章、方法、课程或口播稿转成结构完整的视频。
- **个人 IP 与知识型账号**：保持人物与视觉语言一致，用图解、白板和字幕讲清复杂内容。
- **内容团队**：先配置风格和逐页审阅，再进入合成，减少反复返工。
- **自动化工作流**：让脚本、画面、声音、字幕、封面和交付记录使用同一份生产上下文。

```text
Brief → 内容结构 → 视觉设计 → 口播与时序 → 动效与字幕 → 封面 → 交付
```

## 你会得到什么

| 结果 | 用途 |
| --- | --- |
| 标题命名的 MP4 成片 | 直接审阅、剪辑或进入发布流程 |
| 横屏、竖屏与平台封面 | 针对不同展示位置重新构图，而不是简单裁切 |
| 口播稿、字幕和分镜 | 方便内容复核、二次编辑与团队协作 |
| `delivery.html` | 在一个页面中查看成片、封面、文案和相关素材 |
| 结构化制作记录 | 支持局部修复、复用已有结果和问题定位 |

## 看它如何工作

[![Codex Video Workflow 成片示例](media/showcase/workflow-film/poster.jpg)](media/showcase/workflow-film/codex-video-workflow.mp4)

这支示例片展示的不是一组装饰模板，而是内容如何进入视频：流程节点表达阶段推进，曲线表达趋势变化，关系线表达因果，产品界面表达操作状态，个人 IP 与白板页面负责知识讲解。

- 动效绑定具体内容与表达目的，不随机堆叠效果。

- 横屏、竖屏、个人 IP、手绘白板和平台封面使用各自适合的构图规则。
- 口播、字幕和镜头切换共享同一套真实时序。

## 核心能力

### 内容先于模板

工作流先识别受众、观点、步骤、证据、转折与结论，再为每个场景选择合适的视觉任务。教程可以变成步骤与检查点，数据可以变成趋势与拐点，复杂关系可以变成可追踪的路径。

### 动效服务于解释

画面的动作需要回答一个问题：它是在揭示、比较、连接、追踪、累积、检查，还是完成一次状态变化。这样生成的视频更接近讲解片、产品片和信息可视化，而不是会动的 PPT。

| 信息关系与路径 | 产品状态与操作 |
| --- | --- |

### 字幕与声音共同设计

字幕不是最后盖在视频上的文字层。它从最终口播时序生成，并与关键词强调、画面安全区、横竖屏比例和内容密度一起规划。配置台提供适合教程、产品、观点、数据、双语与移动端内容的字幕选择。

[![字幕设计与选择界面](media/showcase/core-demo/config-caption-gallery.png)](media/showcase/core-demo/config-caption-gallery.png)

### 独立的封面设计

封面从视频的真实内容承诺出发，再针对列表卡片、横屏播放器、竖屏信息流和个人主页重新构图。不同平台获得自己的安全区和视觉层级，而不是把同一张图机械裁成多个比例。

个人 IP 路线使用一致的人物锚点和原生页面设计，适合课程、方法论和创作者讲解。白板能力会在稳定页面上逐步描线、圈选节点和揭示关系，同时保持字幕位于最上层。

## 两种使用方式

| 模式 | 适合场景 | 工作方式 |
| --- | --- | --- |
| **全自动** | 已有清晰 Brief，希望直接获得视频包 | 自动完成内容规划、语音时序、页面、字幕、封面与交付整理 |
| **配置与审阅** | 希望先决定风格，或需要团队逐页确认 | 先生成配置台和页面审阅结果，确认后继续合成 |

两种模式使用同一套内容、视觉和交付合同，因此可以从快速生产自然切换到精细审阅。

## 快速开始

### 1. 安装 Skill

```bash
git clone https://github.com/wpowen/videocreat.git
cd videocreat

export CODEX_HOME="${CODEX_HOME:-$HOME/.codex}"
mkdir -p "$CODEX_HOME/skills/codex-video-workflow"
rsync -a SKILL.md scripts/ assets/ references/ templates/ vendor/ \
  "$CODEX_HOME/skills/codex-video-workflow/"
```

安装后重启 Codex，让 Skill 目录重新加载。

### 2. 用自然语言开始

全自动示例：

```text
请使用 codex-video-workflow，把这份 Brief 生成一条 16:9 的中文方法讲解视频。
使用全自动模式，同时生成字幕、平台封面和交付页面。
```

配置与审阅示例：

```text
请使用 codex-video-workflow，先为这份 Brief 生成中英双语配置页。
让我选择画幅、视觉风格、字幕、封面和逐页内容，确认后再继续合成。
```

命令行入口、参数和完整工作流约束请参阅 [SKILL.md](SKILL.md)。

## 内置能力模块

| Skill | 作用 |

| `codex-video-workflow` | 统筹内容、语音、页面、动效、字幕、合成与交付 |

## 使用边界

- 本项目生成的是**发布前可审阅的视频包**；素材授权、平台规则、AI 标识与最终人工审稿仍由发布者确认。
- 需要生成式图片或原生平台封面时，应在支持 `image_gen` 的 Codex 环境中完成生成与检查。
- 配置目录展示的是可选择的设计能力，不代表每个组合都是一支独立成片。
- 自动字幕路由仍有少量已知回归场景；关键项目建议在配置页中人工确认字幕方案。

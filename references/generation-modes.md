# Generation Modes

The workflow supports two product-level generation modes. These are separate from the low-level renderer mode (`recommended` / `fallback`).

## Full Auto

`full-auto` is explicit opt-in only.

- Entry: `--generation-mode full-auto`, `--full-auto`, `--auto`, or a matching `brief.generationMode`.
- Input: brief, topic, script,素材稿, and any authorized local material.
- Behavior: preserve the existing one-pass workflow: planning, script, assets, voice, subtitles, render, QC, package, and delivery.
- Stop condition: `renders/final.mp4`, `delivery.html`, `logs/qc.json`, and all required workflow evidence are written.
- Human action: none unless a hard gate fails.

## Semi Auto / Custom

`semi-auto` is the default for ordinary topic/script intake.

- Entry: no generation-mode flag, `--generation-mode semi-auto`, `--generation-mode custom`, or a matching `brief.generationMode`.
- Input: topic,口播稿,素材稿, or user constraints.
- Behavior: prepare planning/material/image evidence, generate a configuration page, then stop before final composition unless the caller explicitly composes.
- Stop condition before compose: `semi-auto-config.html`, `workflow/semi-auto-config.json`, and `workflow/generation-mode-contract.json` exist.

### Stage Contract

1. Prepare
   - System runs search/material planning when required, generates or normalizes narration, and writes initial image/material plans.
   - Required evidence includes `workflow/content-presentation-design.json`, `workflow/image-generation-strategy.json`, `workflow/image2-prompts.json`, `workflow/media-routing-plan.json`, and `workflow/material-candidate-pool.json`.
2. Configure
   - Show a redesigned configuration page with:
     - base parameters: horizontal/vertical, resolution, FPS;
     - all supported visual motion templates with clear animated previews;
     - expanded premium color systems in compact selectable palette rows;
     - all 68 caption styles from `assets/caption-style-catalog.json` as selectable rows with the checkbox on the left and the real subtitle treatment preview on the right;
     - material source toggles for free素材 search and local video material;
     - personal IP modes fused with hand-drawn foreground, knowledge-card, and presenter examples;
     - voice choices, including Chinese, English, bilingual, dialect/accent when local assets support it, and all supported speech styles.
   - The page is generated by `scripts/build-semi-auto-config-html.mjs`.
3. Page Edit
   - Show pages through `page-review.html`.
   - Each page can be edited by page id and TDS:
     - T: text/content;
     - D: design/layout/visual metaphor;
     - S: subtitle/style/safe area.
   - Page-level edits should use `scripts/incremental-video-edit.mjs` when the requested patch does not invalidate the full project.
4. Compose
   - After the user confirms configuration and page content, run the normal final render and QC path.
   - The final package must still pass the same quality gates as full-auto output.

## Required Contract Artifact

Every generated package writes `workflow/generation-mode-contract.json` with:

- selected generation mode;
- supported mode definitions;
- default horizontal canvas rule;
- semi-auto stage definitions;
- configuration sections, including voice mode choices;
- page-level TDS edit contract;
- capability inventory, including motion-template count and caption-style count;
- decision ownership for content, design, interaction, animation, final composition, and QC.

## Rules

- Full-auto requires explicit user or caller opt-in.
- Topic-only or口播稿-only intake defaults to the configuration page so the user can choose full-auto, personal-IP, hand-drawn, vertical short-form, motion template, caption style, material source, voice, cover targets, and compose timing before final render.
- Horizontal 16:9 stays the default video canvas. Only explicit vertical/short-form requests switch to 9:16. If the user intent is ambiguous, ask before rendering.
- Semi-auto must stop at the configuration/page-review gate unless composition was explicitly requested.
- Final video frames must not show page numbers, scene counters, renderer names, framework/library names, capability labels, or technical implementation badges.
- Configuration and review HTML may expose workflow choices for operators, but simulated video frames inside those pages must remain viewer-facing.

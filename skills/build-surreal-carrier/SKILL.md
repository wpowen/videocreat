# Build Surreal Carrier

Translate one abstract idea into one memorable physical carrier with a clear transformation and usable overlay space.

## Workflow

1. Read [the shared production contract](../_visual-series-core/production-contract.md).
2. Read [the scene design contract](references/design-contract.md).
   Load `references/prompt-contract.json` as the machine-readable source of truth for metaphor topology, material/light, reject rules, and QC. Do not replace it with the central catalog skeleton.
3. Normalize `topic`, `carrier`, `insideWorld`, `transformation`, `direction`, and `transitionFunction`.
4. Test the semantic mapping in words: carrier identity, what each internal element means, and how the transformation connects adjacent beats.
5. Generate one focal object only. Preserve negative space and the lower subtitle band.
6. Reject beautiful but unrelated scenery, multiple competing metaphors, unclear transformation direction, or body-horror distortion.

## Output contract

Return the image, carrier-to-topic mapping, transition role, final prompt, and metaphor/safe-space audit.

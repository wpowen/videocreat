# Interface Plate Design Contract

## Content schema

- A product goal and user task.
- A stable original app shell and component map.
- One clearly selected module or state.
- A before/after or workflow transition when claimed.
- A coherent data story with a stated direction.
- Planned overlay anchors for exact labels added deterministically.

## Visual language

Use a clean premium fictional SaaS interface on a light neutral stage, strict grid, calm cobalt accent, restrained depth, realistic component spacing, and one focal module. Use meaningful chart shapes and workflow states, but reserve exact UI copy for deterministic overlays unless it can be proofread. Maintain the same shell and design tokens across a series.

## Reject when

- The screen merely looks like SaaS but explains no user task or state.
- More than one selected state competes for focus.
- Chart direction, summary metric, and claimed outcome disagree.
- The layout resembles a named real product or contains browser/brand cues.
- Important controls, chart points, or workflow nodes enter the lower 18%.
- Auto-generated axis ticks, step numerals, or timestamps appear outside the exact text whitelist.
- A claimed evidence count is only approximate. Waveform flags, alerts, selected items, and repeated markers must be counted against the input one by one.
- Supporting cards contain placeholder bars but no explanatory job.

## Repair map

- Decorative dashboard: remove generic cards and enlarge the one functional sequence being explained.
- Ambiguous state: use a single selection treatment and a clear before→processing→ready progression.
- Evidence gap: add a coherent metric region and connect it visually to the selected feature.
- Extra UI copy: render unlabeled ticks and empty overlay anchors; exact axis labels and support copy belong to deterministic overlays.
- Automatic step badges: replace unrequested numerals with icon-only or blank state tokens while keeping the selected state unique.

Use only these exact Chinese strings and numbers; no other readable text, no real product resemblance, and keep the lower 18% empty.

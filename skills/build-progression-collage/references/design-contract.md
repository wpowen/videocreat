# Progression Collage Design Contract

## Content schema

- One base identity with measurable invariant features.
- Two to six ordered states.
- An explicit allowlist of what changes in each state.
- Locked camera, lens, distance, crop, background, and key-light direction.
- A progression that is visually distinguishable without labels.

## Visual language

Use an editorial contact sheet with equal cells, identical gutters, stable color grade, and one repeated subject scale. The grid is evidence of change, not a decorative collage. Prefer reference-bound sequential edits for identity-sensitive subjects.

## Reject when

- Silhouette, proportions, handle/limb placement, camera distance, or viewpoint changes unintentionally.
- Lighting direction or background tone drifts between cells.
- State order is visually ambiguous.
- More than the declared variables change.
- The last row or subject enters the subtitle-safe band.
- A multi-cell bitmap is generated in one model call instead of assembling separately validated state assets.

## Repair map

- Identity drift: return to the base reference and edit only the allowed material/age/state variable.
- Camera drift: regenerate the offending state with explicit lens, crop, horizon, and subject bounding-box locks.
- Weak progression: exaggerate the allowed state difference without altering identity.
- Hidden branches: use one leafless edit as the structural anchor for all bare or budding states; compare visible twig endpoints before assembly.

## Forward-test brief

Create a 9:16 four-state editorial contact sheet of the same small Japanese maple bonsai across early spring buds, full summer leaves, red autumn foliage, and bare winter branches. Lock the exact trunk curve, branch structure, ceramic pot, camera distance, 50mm front three-quarter view, grey studio background, and soft key light from upper left. Change only leaves and seasonal surface moisture. No text. Leave a calm lower safe band outside the four-cell grid.
